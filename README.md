# PrepTrack – Interview Preparation Dashboard

## Overview
PrepTrack is a productivity dashboard designed for students preparing for technical interviews. It visually tracks preparation progress across multiple categories.

## Features
- DSA progress tracking
- Aptitude preparation monitoring
- Mock interview progress
- Interactive UI dashboard

## Technologies Used
HTML  
CSS  
JavaScript  

## How to Run
1. Download or clone the repository
2. Open `index.html`
3. Click buttons to update progress
